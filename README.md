# FunChat - React Native Chat App

![funchat](https://github.com/user-attachments/assets/1760bcb3-f8cf-47cc-901b-cf6d90d542d3)

FunChat is a simple and fun chat application built with React Native, allowing users to send and receive messages in real-time. The app is designed to be fast, secure, and easy to use.

## Features
- Real-time messaging Firebase and Gestream.io.
- Secure authentication and user management.

- Clean and intuitive user interface.
- Support for both iOS and Android platforms.
- Typing indicators, message read receipts, and more.

## Technologies Used
- **React Native** for building the cross-platform mobile application.
- **TypeScript** for coding and logic.
- **Firebase** for real-time messaging and notification.
- **Zustand** for state management.
- **React Navigation** for navigating between screens.
- **Axios** for handling API requests.

## Installation

You can use either `npm` or `yarn` to install the dependencies and run the project.

### Using Yarn or Npm

1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/funchat.git
    ```
2. Navigate to the project directory:
    ```bash
    cd funchat
    ```
3. Install the dependencies:
    ```bash
    yarn install
    ```
    or
    ```bash
    npm install
    ```
5. Start the app:
    ```bash
    yarn start
    ```
    or
    ```bash
    npm start
    ```

## Running on iOS and Android

To run the app on a specific platform, follow these steps:

- For **iOS**:
    ```bash
    yarn ios
    ```
    or
    ```bash
    npm run ios
    ```

- For **Android**:
    ```bash
    yarn android
    ```
    or
    ```bash
    npm run android
    ```
